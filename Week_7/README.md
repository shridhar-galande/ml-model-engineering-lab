# Model Standardization and Optimization

Hands-on labs for converting machine learning models to ONNX, applying
compression techniques, and benchmarking inference performance.

## Labs

| Folder | Focus |
|---|---|
| `lab0_sklearn_onnx/` | Convert and benchmark scikit-learn Iris classifiers with ONNX. |
| `lab1_onnx_conversion/` | Export MobileNetV2 from TensorFlow/Keras to ONNX. |
| `lab2_compression/` | Compare ONNX quantization, TFLite INT8 quantization, and pruning. |
| `lab3_benchmarking/` | Measure model size, latency, throughput, and memory use. |

Each lab includes a Python script and a Jupyter notebook. Run labs 1–3 in
order for the MobileNetV2 workflow. Missing prerequisite models are
regenerated by the later labs when possible.

## Requirements

- Python 3.9–3.11
- Internet access on the first MobileNetV2 run to download pretrained
  ImageNet weights
- CPU is sufficient; no GPU is required

## Setup

From the project root, create and activate a virtual environment:

```bash
python -m venv .venv
```

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

```bash
# macOS or Linux
source .venv/bin/activate
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the labs

Run scripts from the project root:

```bash
python lab0_sklearn_onnx/sklearn_onnx_iris.py
python lab1_onnx_conversion/lab1_onnx_conversion.py
python lab2_compression/lab2_compression.py
python lab3_benchmarking/lab3_benchmarking.py
```

Alternatively, start Jupyter with `jupyter notebook`, open a lab's `.ipynb`
file, and run its cells from top to bottom.

## Outputs

Labs generate model files, plots, and benchmark results in local
`artifacts/` folders. These generated files are excluded from Git; run a
lab to create them. Performance results vary by machine.
